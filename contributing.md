*   Wait for all packages to install (takes ~3 minutes)

### Step 3: Configure AI Model

*   Open `config.json` and choose between local or cloud AI
*   For cloud AI: Add your API key (OpenAI, Anthropic, etc.)
*   For local AI: Download a model (supports LLaMA, Mistral, CodeLlama)

### Step 4: Start Analyzing Code

*   Run `xeno analyze --path ./my-project`
*   Run `xeno generate --type docs --path ./my-project`
*   Run `xeno test --path ./my-project`
*   Or use the interactive mode: `xeno interactive`

> **💡 Pro Tip:** Use `xeno watch` to continuously monitor code changes and get real-time suggestions.
